# Kumpulan Doa Harian

Situs statis berisi zikir pagi dan petang, zikir setelah shalat fardhu, dan doa harian, dengan teks Arab, latin, dan terjemahan Indonesia.

## Lihat situs
https://nubialipa.github.io/kumpulan-doa/ (setelah deploy selesai)

## Struktur
- `site/index.html`: seluruh situs dalam satu file statis.
- `.github/workflows/deploy.yml`: deploy folder `site/` ke GitHub Pages setiap push ke `main`.
- `CLAUDE.md`: aturan proyek untuk Claude Code.

## Catatan
Teks bacaan dirangkum dari rujukan umum. Cocokkan lafal dan jumlah bacaan dengan buku zikir rujukan sebelum dibagikan.
